# Susovan Ghara // Infrastructure

Modern technical resume / portfolio website built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The `dist/` folder is ready to deploy to GitHub Pages or another static host.

## Personalise

Update:
- GitHub URL in `src/main.jsx`
- Experience/project details
- Certification list
- Contact links
- Meta description/title in `index.html`
